# Test Plan — COMFY Website

## 1. Project Overview

**Project Name:** COMFY Website  
**Website:** https://comfy.ua/  
**Testing Type:** Manual Testing  
**Project Type:** E-commerce Website

The purpose of this project is to perform manual testing of the COMFY e-commerce website to evaluate its functionality, usability, and responsiveness.

## 2. Testing Objectives

- Verify the main website functionality.
- Check product search and filtering.
- Verify product pages and product information.
- Test adding and removing products from the shopping cart.
- Check the checkout process.
- Identify and document defects.
- Verify the website's responsive behavior.

## 3. Scope of Testing

### In Scope

- Homepage
- Navigation menu
- Product catalog
- Product search
- Product filters and sorting
- Product details page
- Shopping cart
- Checkout process
- Forms and input validation
- Responsive layout
- API requests related to tested functionality, where accessible

### Out of Scope

- Real purchases and payments
- Testing internal administrative functionality
- Load and performance testing
- Security penetration testing
- Automated testing

## 4. Test Types

- Functional Testing
- UI Testing
- Usability Testing
- Positive Testing
- Negative Testing
- Regression Testing
- Responsive Testing
- API Testing

## 5. Test Environment

**Website:** https://comfy.ua/  
**Testing Approach:** Manual  
**Browser:** Google Chrome  
**Operating System:** Windows  
**Tools:**
- Chrome DevTools
- Postman
- GitHub
- Google Sheets (if required for test documentation)

## 6. Test Deliverables

The following testing artifacts will be prepared:

- Test Plan
- Test Checklist
- Test Cases
- Bug Reports
- Screenshots and evidence
- API Collection
- Test Summary Report

## 7. Entry Criteria

- The website is accessible.
- The main website pages are available.
- Testing environment is prepared.

## 8. Exit Criteria

- All planned test cases have been executed.
- Test results have been documented.
- Identified defects have been reported.
- Test Summary Report has been prepared.

## 9. Risks and Limitations

- Website content and functionality may change during testing.
- Some features may require user authentication.
- Real orders and payments will not be completed.
- Some API endpoints may not be publicly accessible.

## 10. Test Status

**Status:** In Progress
