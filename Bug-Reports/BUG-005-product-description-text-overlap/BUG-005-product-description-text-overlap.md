# BUG-005 — Product Description Text Overlaps on Product Page

**Bug ID:** BUG-005  
**Title:** Product description text overlaps on the product page after clicking a promotional banner  
**Module:** Product Details Page / UI  
**Severity:** Medium  
**Priority:** Medium  
**Environment:**
- OS: Windows 11
- Browser: Google Chrome
- Browser Mode: Incognito
- Website: https://comfy.ua/ua/

### Preconditions
1. Open the COMFY website.
2. Make sure the homepage is loaded.

### Steps to Reproduce
1. Open the COMFY homepage: https://comfy.ua/ua/
2. Locate the promotional banner featuring the Bosch vacuum cleaner.
3. Click the promotional banner.
4. Wait until the product details page loads.
5. Scroll down to the product description section.
6. Observe the text layout.

### Expected Result
The product description and its text elements should be displayed correctly without overlapping. All product information should be readable and properly aligned.

### Actual Result
Several text elements in the product description section overlap each other. Some headings and descriptions are displayed on top of other content, making the information difficult to read.

### Severity
Medium — The issue affects the readability and presentation of product information.

### Priority
Medium — The layout issue should be fixed to ensure a consistent user experience.
